# Векторизованный K-Means (NumPy From Scratch)

Программная реализация классического алгоритма машинного обучения K-Means Clustering с нуля.

## Архитектурные особенности:

* **Полная векторизация:** Вычисление евклидова расстояния от всех точек до всех центроид выполняется за одну матричную операцию:
  `np.linalg.norm(X[:, np.newaxis] - self.cluster_centers_, axis=2)`
* **Безопасность (Edge Cases):** предусмотрен механизм защиты от пустых кластеров, при котором вырожденный центроид переинициализируется случайным вектором из обучающей выборки.
* **Кастомная обработка ошибок:** Использование наследования от `ValueError` для обработки исключительных ситуаций.

## 🛠 Технический стек:
* `Python 3`
* Матричные вычисления: `NumPy`
* Визуализация данных: `Matplotlib`, `Seaborn`
